CodeAlpha Data Analytics Task 2 – Exploratory Data Analysis

Overview

This project performs Exploratory Data Analysis (EDA) on the Sample Superstore dataset to understand sales, profit, product categories, and monthly sales trends.

Objectives

- Understand dataset structure and data types.
- Check missing values and duplicate rows.
- Calculate descriptive statistics.
- Analyze sales and profit by category.
- Explore the relationship between sales and profit.
- Identify potential sales outliers.
- Analyze monthly sales trends.

Visualizations

1. Sales Distribution
2. Total Sales by Category
3. Total Profit by Category
4. Sales vs Profit
5. Sales Outlier Detection
6. Monthly Sales Trend

Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

Project File

- "CodeAlpha_EDA.ipynb" – Notebook containing the analysis and visualizations.

Conclusion

This project uses EDA techniques to explore sales patterns, profitability, and trends to support data-driven decision-making.
